# models

Request/response DTOs and shared schema helpers.

Files:
- `candle.rs` - candle DTO matching Hyperliquid response.
- `chart.rs` - chart query parameters and snapshot payload.
- `double_top.rs` - double top response payloads.
- `health.rs` - health response payload.
- `interval.rs` - shared interval constants and helpers.
- `vwap.rs` - VWAP query parameters and payloads.
- `mod.rs` - module exports.
